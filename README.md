## 🌟 Overview
**SAP Copilot** is a consultant-level enterprise SAP learning and simulation platform designed by **TagSkills**. It covers end-to-end business processes, SPRO customizing, transparent tables, and interactive simulations across **SAP MM (Materials Management / Sourcing & Procurement)** and **SAP EWM (Extended Warehouse Management)**.

---

## 🚀 Key Features

### 📦 SAP MM (Materials Management)
- **Organizational Structure**: Client, Company Code, Plant, Storage Location, Purchasing Organization & Groups.
- **Master Data**: Material Master Views, Business Partner / Vendor Master, Info Records, Source Lists.
- **Procurement Lifecycles**: Standard P2P, Consignment, Subcontracting, Third-Party, Stock Transport Orders (STO).
- **Inventory Management**: Movement Types (101, 201, 261, 301, 311, 551, etc.), Physical Inventory, Split Valuation.
- **Valuation & Account Determination**: OBYC Valuation Grouping, Valuation Class, Automatic Account Assignment (BSX, WRX, GBB, PRD).
- **Invoice Verification (LIV)**: MIRO 3-Way Matching, Price/Quantity Variances, Debit/Credit Memos.

### 🏭 SAP EWM (Extended Warehouse Management)
- **Warehouse Structure & SCU**: Warehouse Hierarchy, Storage Types, Sections, Bins, Activity Areas, Bin Sorting (`/SCWM/SBST`).
- **Inbound & Putaway**: Inbound Delivery (`/SCWM/PRDI`), Dynamic Capacity Checks (Methods 1–4), PACI, Storage Type Search Sequences.
- **Handling Unit & PackSpec**: Packaging Materials (`VERP`), SSCC-18, PackSpec Condition Technique (`/SCWM/PACKSPEC`).
- **Advanced Inbound**: Process-Oriented Storage Control (POSC), Deconsolidation (`/SCWM/DCONS`), Value Added Services (VAS), Layout-Oriented Storage Control (LOSC), Robotics / AGV / AMR Integration.
- **Outbound & Picking**: Sales Order (`VA01`) to PGI (`/SCWM/PRDO`), FIFO/FEFO/LIFO picking, Warehouse Order Creation Rules (WOCR), Pick Denial (`BIDN`), Reversals.
- **Physical Inventory**: Annual, Continuous, Cycle Counting, Low Stock Checks, Difference Analyzer (`/SCWM/DIFF_ANALYZER`).
- **Queue & Resource Management**: 5-Tier Queue Determination Matrix, Resource Groups, System-Guided Interleaving.
- **RF Framework**: 5-Layer Screen Architecture, Verification Profiles, Interactive `/SCWM/RFUI` Simulator.
- **Warehouse Movements**: Replenishment (`/SCWM/REPL`), Scrapping (`551`), `ADHU` & `ADPROD` Stock Posting Changes.
- **PPF & Wave Management**: Post Processing Framework (`SPPFP`), Wave Templates, Cut-Off Scheduling, Automatic Wave Determination (`/SCWM/WDG_RULES`).
